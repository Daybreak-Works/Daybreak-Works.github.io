# Contributing / Contribuciones

Welcome: corrections, translations, accessibility fixes, technical documentation links and design improvements.
Please open an issue before significant visual restructuring. Pull requests should describe the change, note how both language versions are affected, and include a screenshot when the interface changes.
Only maintainers of Daybreak Works approve changes and official releases. Do not add personal EFI identity values, Apple proprietary files, vendor logos without permission, or unverified hardware compatibility claims.
